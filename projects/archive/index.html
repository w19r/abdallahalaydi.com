Family Archive

A resilient, data-driven memorial archive built to preserve historical family photographs, timelines, and shared memories with zero recurring hosting overhead.

01 / PROBLEM & GOAL

Family photos scattered across messaging apps lose their dates, stories, and original resolution over time. The goal was to build a fast, distraction-free archive that works offline as an installable mobile app and allows non-technical family members to publish new memories directly from Telegram.

02 / SYSTEM ARCHITECTURE

Static Edge & PWA Frontend GitHub Pages + Cloudflare

Zero-framework modular vanilla JS frontend with Service Worker caching, progressive blur-up image loading, pinch-to-zoom lightbox, and client-side printable PDF generation.

Comments & Auth Backend FastAPI + PostgreSQL

REST API deployed on Render handling user accounts, PBKDF2-HMAC-SHA256 password hashing, JWT sessions, and sliding-window in-memory rate limiting against spam.

Git-Backed CMS & Telegram Control GitHub API + Webhook Bot

Sending a photo to a private Telegram bot automatically generates thumbnail, viewing, and blur variants via Pillow, commits them to GitHub, and updates the live JSON index.

03 / TECH STACK

Python / FastAPI PostgreSQL Vanilla JS (ES6+) Cloudflare Workers GitHub REST API Telegram Bot API Service Workers (PWA)
